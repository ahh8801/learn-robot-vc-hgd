## EXPLAIN

### 1. 이 강의는 어디서 왔나

교재 「로봇 밸류체인」 3장을 블록 하나씩 옮긴 실습판이다. 교재의 핵심 질문은 하나다: **로봇 밸류체인의 어느 고리에서 자동차 부품사가 가진 기술과 생산 역량으로 새 사업 기회를 잡을 수 있는가?**

| 교재 | 이 강의 |
|---|---|
| 표지 · 부록(출처 목록) | Block 0 준비 — 자료 읽는 법 |
| 1장 로봇 밸류체인 지도 | Block 1 |
| 2장 핵심 부품과 공급 구도 | Block 2 |
| 3장 자동차 부품사의 진입 기회 | Block 3 |

### 2. 오늘 쓸 자료

| 파일 | 무엇 |
|---|---|
| `facts.csv` | 교재에 쓴 숫자만 모은 표. 23행. 열: 번호 · 장 · 항목 · 값 · 단위 · 기준연도 · 출처 · 교차확인 · 비고 |
| `sources.md` | 출처 목록 S1~S15 — 제목 · 기관 · 발행일 · 주소 · 신뢰도 |
| `textbook/ch1~3.md` | 교재 본문 |

모두 **공개 자료**에서 뽑은 숫자다. 자료 기준일은 2026-10-31이다.

### 3. 숫자를 읽는 법 — facts.csv의 '교차확인' 열

| 표시 | 뜻 | 교재·대시보드에서 쓰는 법 |
|---|---|---|
| 확인 | 서로 다른 출처 두 곳 이상에서 같은 숫자를 확인했다 | 그대로 쓰고 [S번호]를 붙인다 |
| 부분 확인 | 출처끼리 숫자가 다르다 | 범위로 쓰고 "보도 기준 추정"이라고 밝힌다 |
| 단일 출처 | 한 곳에서만 확인했다 | "회사 발표 기준"처럼 출처의 성격을 밝히거나, 쓰지 않고 보류한다 |
| (값이 '미확보') | 공개 자료로 찾지 못했다 | 지어내지 않고 '미확보'로 둔다 |

### 4. 케이스 — 보도마다 숫자가 다를 때

휴머노이드 원가에서 액추에이터가 차지하는 몫을 두 매체가 다르게 보도했다. 한국경제는 "60% 이상으로 알려졌다" [S9], 아이뉴스24는 "40~60%" [S10]라고 썼다. 교재는 두 보도를 합쳐 **"40~60%(보도 기준 추정)"** 로 쓰고 두 출처를 함께 붙였다. 숫자 하나를 골라 단정하면 출처끼리 다르다는 사실이 사라진다.

## EXECUTE

Phase A 출력 직전에 `{SKILL_DIR}`를 이 스킬 폴더의 실제 경로로 바꿔 보여 준다.

```
로봇 밸류체인 실습 준비를 해 줘.
1. 내 홈 폴더에 robot-vc 폴더를 만들고, 그 안에 data 와 outputs 폴더를 만들어 줘.
2. {SKILL_DIR}/assets/lab 안의 파일과 textbook 폴더를 robot-vc/data 로 복사해 줘.
   원본은 고치지 않는다.
3. Python이 있는지 확인해 줘. 이 실습은 Python 표준 라이브러리만 쓴다(설치할 패키지 없음).
4. data/facts.csv 를 읽고 전체 행 수, '교차확인' 열의 값별 행 수,
   값이 '미확보'인 행의 번호와 항목을 보여 줘.
5. 결과를 robot-vc/outputs/env_check.txt 에 항목별 OK / 조치 필요로 적어 줘.
6. 숫자를 지어내거나 facts.csv 를 고치지 마.
```

끝나면 데스크톱 앱에서 **새 세션 → Local → 폴더 선택**으로 `robot-vc` 폴더를 열고, 그 세션에서 `/learn-robot-vc-hgd`로 Block 1을 이어 가라고 안내한다.

### 확인할 것 (Phase B)

`~/robot-vc/outputs/env_check.txt`와 `~/robot-vc/data/`를 직접 읽어 확인한다.

- `data/facts.csv` · `data/sources.md` · `data/textbook/ch1.md`~`ch3.md`가 있다
- facts.csv 전체 23행, 교차확인 '확인' 18행, 값 '미확보' 2행 (F17 산업용 로봇 부품별 원가 비중 · F18 감속기 업체별 세계 점유율)
- Python이 OK

행 수가 다르면 정답을 바로 주지 말고 이 프롬프트를 붙여 넣게 한다.

```
facts.csv 행 수가 23이 아니야. 머리글 줄을 행으로 셌는지, 파일 앞의 BOM 때문에
첫 열 이름이 깨졌는지 확인하고, utf-8-sig 로 다시 읽어서 세어 줘.
```

정답: 2번. 출처끼리 숫자가 다른 '부분 확인' 숫자는 범위로 쓰고 "보도 기준 추정"이라고 밝힌 뒤 두 출처를 함께 붙인다 — 교재가 이 숫자를 쓴 방식 그대로다. 1번처럼 60%로 단정하면 출처끼리 다르다는 사실이 사라져 읽는 사람이 확정값으로 오해한다. 3번의 50%는 어느 출처에도 없는 숫자를 새로 만든 것이라, 계산처럼 보여도 지어낸 숫자다. 현장에서는 숫자 옆의 출처 번호와 '추정' 표시가 그 숫자를 얼마나 믿어도 되는지를 알려 주는 장치다.
