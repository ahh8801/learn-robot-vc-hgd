# Block 1: 로봇 밸류체인 지도 — 세 고리와 숫자로 보는 크기

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 IFR World Robotics 2025 보도자료 [S1]: https://ifr.org/ifr-press-releases/news/global-robot-demand-in-factories-doubles-over-10-years
> 📖 교재: ~/robot-vc/data/textbook/ch1.md
> ```

## EXPLAIN

이 블록의 핵심 질문: **로봇 산업은 어떤 고리로 나뉘고, 각 고리에서 돈은 어떻게 버는가?** (교재 1장)

### 1. 용어

| 용어 | 뜻 |
|---|---|
| 밸류체인(가치사슬) | 원재료·부품에서 완제품, 그리고 고객이 쓰기까지 가치가 더해지는 단계를 차례로 이은 것 |
| 업스트림 · 미드스트림 · 다운스트림 | 부품 → 로봇 본체 → 설치·운영(시스템 통합, 유지보수, 서비스형 로봇) |
| 시스템 통합(SI) | 로봇 한 대를 실제 공정에 맞게 설계·설치·시운전해 "일하는 설비"로 만드는 일 |
| 신규 설치 대수 | 그해 새로 공장에 들어간 산업용 로봇 수. 해마다의 **수요** |
| 가동 대수 | 지금 공장에서 돌아가고 있는 산업용 로봇 전체 수. 쌓인 **설치 기반** |
| 로봇 밀도 | 제조업 종사자 1만 명당 산업용 로봇 수 |

### 2. 왜 지도부터 그리나 — 세 고리는 돈 버는 방식이 다르다

"로봇 회사가 되어야 하나?"에서 막히지 않으려면 먼저 지도를 그린다. 로봇 산업은 완성 로봇만이 아니라 세 고리로 이루어져 있고, 고리마다 필요한 역량이 다르다.

| 고리 | 무엇을 만드나 | 돈 버는 방식 | 자동차 산업에 빗대면 |
|---|---|---|---|
| ① 부품 | 감속기, 서보모터·액추에이터, 센서·비전, 제어기·소프트웨어 | 로봇 회사에 부품을 대량 납품 | 1·2차 협력사 |
| ② 로봇 본체 | 산업용, 협동, 서비스, 휴머노이드 로봇 | 완성 로봇 판매, 플랫폼·소프트웨어 | 완성차 회사 |
| ③ 도입·운영 | 공정 설계, 설치, 유지보수, 서비스형 로봇 | 프로젝트 수주, 유지보수 계약, 월 사용료 | 딜러·정비·리스 |

숫자로 보면 (facts.csv):

| 지표 | 값 | 기준연도 |
|---|---|---|
| 세계 산업용 로봇 신규 설치 | 542,000대 [S1][S6] | 2024 |
| 세계 산업용 로봇 가동 대수 | 4,664,000대, 전년 대비 9% 증가 [S1][S6] | 2024 |
| 세계 신규 설치 전망 | 575,000대 [S1][S6] — 실적이 아니라 **전망** | 2025 |
| 중국 신규 설치 | 295,000대, 세계 설치의 54% [S1][S2] | 2024 |
| 국내 로봇산업 매출 | 6조1,695억 원, 전년 대비 3.2% 증가 [S4][S5] | 2024 |
| └ 제조업용 / 서비스용 / 부품·소프트웨어 | 3조1,075억 / 1조810억 / 1조9,810억 원 [S4][S5] | 2024 |

세 부문을 더하면 전체 매출과 정확히 같다. 부품·소프트웨어가 국내 매출의 32.1%다 [S5]. 부품 고리가 이미 국내 시장의 큰 덩어리다.

### 3. 케이스 — 로봇을 가장 촘촘히 쓰는 나라, 한국

한국은 제조업 종사자 1만 명당 로봇 1,220대로 로봇 밀도 세계 1위다 [S2][S3]. IFR은 그 배경으로 산업용 로봇을 많이 사는 **전자 산업과 자동차 산업**을 꼽는다 [S2].

- 자동차 부품사는 **이미 로봇의 큰 고객**이다. 용접·도장·조립 라인에서 로봇이 어디서 고장 나고 무엇이 불편한지 현장에서 안다.
- 그런데 **쓰는 만큼 만들지는 못한다.** 2024년 한국 신규 설치는 30,600대 [S1][S6]로 중국 295,000대 [S1][S2]에 비하면 작은 시장이고, 핵심 부품 국산화율은 절반에 못 미친다 [S7][S8].

"가장 많이 쓰는 나라"가 "부품을 만드는 나라"가 될 수 있는지가 이 강의 전체의 질문이다.

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다.

```
~/robot-vc/data/facts.csv 로 로봇 밸류체인 결과 대시보드의 1장 칸을 만들어 줘.
data 원본은 고치지 않는다. facts.csv 에 없는 숫자는 쓰지 않는다.
1. outputs/index.html 을 한 장짜리 대시보드로 만들고 제목은
   "로봇 밸류체인 — 자동차 부품사는 어느 고리에서 기회를 잡을 수 있는가"로 해 줘.
   휴대폰 폭에서도 가로 스크롤이 생기지 않게 해 줘.
2. "1장 밸류체인 지도" 칸에 세계 시장 카드 4개(F01 신규 설치 · F02 가동 대수 ·
   F03 2025년 전망 · F04 중국 신규 설치)와 국내 매출 구조 표(F09 · F10 · F11 · 합계 F07)를 넣어 줘.
   F03 에는 '전망'이라고 붙여 줘.
3. 모든 숫자 옆에 facts.csv '출처' 열의 번호를 [S1][S6] 처럼 붙여 줘.
4. 직접 계산해서 알려 줘:
   (1) F09 + F10 + F11 이 F07 과 같은지
   (2) 부품·SW 비중 = F11 ÷ F07 (소수 첫째 자리 %)
   (3) 중국 비중 = F04 ÷ F01 (정수 %)
   계산값이 facts.csv 비고와 다르면 대시보드에 넣지 말고 나에게 먼저 알려 줘.
```

### 확인할 것 (Phase B)

`~/robot-vc/outputs/index.html`을 직접 읽어 확인한다.

- 1장 칸에 카드 4개(542,000대 · 4,664,000대 · 575,000대(전망) · 295,000대)와 국내 매출 구조 표가 있다
- 세 부문 합 = 6조1,695억 원 (F07과 같음)
- 부품·SW 비중 32.1% · 중국 비중 54%
- 숫자마다 [S번호]가 붙어 있고, facts.csv에 없는 숫자가 없다

비중이 다르게 나오면 정답을 바로 주지 말고 이 프롬프트를 붙여 넣게 한다.

```
부품·SW 비중이 32.1%가 아니야. F11 과 F07 의 '값'에서 '조'·'억'·쉼표를
억 원 단위 숫자로 바꿨는지(1조9,810억 = 19,810억) 확인하고 다시 계산해 줘.
```

## QUIZ

```json
AskUserQuestion({
  "questions": [{
    "question": "우리 회사가 로봇용 교체 부품(유지보수 부품) 사업을 검토한다. 2024년 세계 산업용 로봇 신규 설치는 542,000대, 가동 대수는 4,664,000대다[S1][S6]. 교체 부품 수요의 크기를 가늠할 때 먼저 볼 숫자는?",
    "header": "Quiz 1",
    "options": [
      {"label": "신규 설치 542,000대", "description": "해마다 새로 들어가는 로봇 수"},
      {"label": "가동 대수 4,664,000대", "description": "지금 공장에서 돌아가는 로봇 전체 수"},
      {"label": "2025년 신규 설치 전망 575,000대", "description": "가장 최근 연도의 숫자"}
    ],
    "multiSelect": false
  }]
})
```

정답: 2번. 교체 부품은 이미 공장에서 돌아가는 로봇에서 나오므로, 쌓인 설치 기반인 가동 대수가 먼저다. 1번 신규 설치는 해마다의 새 로봇 수요를 보여 주는 숫자라 새 로봇에 들어가는 부품을 팔 때 맞는 잣대다. 3번은 실적이 아니라 전망이고, 역시 신규 설치 숫자다. 사업에 따라 보는 숫자가 다르다 — 신규 부품 납품이면 신규 설치, 유지보수·교체 부품이면 가동 대수부터 본다.
