## 실습 MVP 계획

- 데이터: `../facts.csv` (23행, 출처 S1~S15, 자료 기준일 2026-10-31) — 교재 숫자의 유일한 원천

- 확인할 핵심 수치 후보 (교재 값과 직접 계산 값 일치 확인):

  - Block 2: 국산화율 최저 감속기 35.8% · 최고 제어기 47.9% · 50% 넘는 부품 0개
  - Block 3: 현대차그룹 미국 로봇 공장 연 30,000대 · HL만도 목표 2조3,000억 원 · 10%

## 원본과 다르게 정한 곳

- **블록 4개, 배포·공유 블록 없음** — 사용자가 "준비 + 교재 3장"으로 정했다. course-forge 기본(끝의 두 블록 = 배포·공유)과 다르다. 공개는 이 learn 스킬을 만드는 쪽(6단계)에서 하고, 수강생용 공개·공유 안내는 Block 3 끝과 GUIDE.md에 짧게 둔다.
- **Block 0에도 퀴즈 1문항** — 사용자가 "블록마다 퀴즈 1문항"을 정했다. course-forge 기본은 Block 0 퀴즈 없음. 재료는 교재 2장 질문 3(자료 표기 판단)으로, 자료 읽는 법을 다루는 Block 0에 맞다.
- 원본이 강의 저장소 Day 폴더가 아니라 이 폴더의 교재이므로 저장소를 내려받지 않는다.
